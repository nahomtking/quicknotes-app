# QuickNotes

QuickNotes is a simple browser-based note-taking app that lets users create, organize, search, and delete notes by category. Notes are saved in the browser using localStorage, so they remain available after refreshing or reopening the page.

## Features

- Add notes with Personal, Work, or Study categories
- Display notes as organized cards
- Delete notes
- Validate empty notes and notes over 200 characters
- Search notes while typing
- Case-insensitive note search
- Display the total number of notes
- Save notes using localStorage
- Responsive layout for mobile and desktop

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` with Live Server.
4. The QuickNotes app will open in your browser.
